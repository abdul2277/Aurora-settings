# Changelog

## 1.39.0
See "New in 1.39" in README.md.

Fixed: Store showed finished updates as still pending; update check hid GitHub rate limits; download stream errors could crash the app; a background check could discard a downloaded update; failed portable updates could delete the working app; manual update checks used a stale cache; update-download timer leaked; Drop notification key used a missing field; the Edge AI switch left page-content access on; four add-on ids were shared by two add-ons each; the Bluetooth profile filter dropped the default A2DP mode.
